== panel-clades/src/abi/ — Idris2 ABI Formal Proofs

=== Purpose

Idris2 definitions of the panel-clades C ABI, and the properties of
those definitions that the type checker can establish: tag encodings,
non-null handles, non-empty identifiers, alignment arithmetic, and the
graded resource contracts over typed-wasm's grade kernel.

=== Boundary

* *Verified by*: the Idris2 0.8.0 type checker, run by
`+scripts/check-abi.sh+` and CI (`+build-validation.yml+`,
`+panel-clades-abi+`). Every module under `+PanelClades/ABI/+` is checked.
The gate fails if a module is missing from the ipkg or uses an escape
hatch.
* *Implemented by*: `+panel-clades/ffi/zig/+`. The Zig side restates the
tags and sizes by hand. *Nothing checks that it agrees with these
definitions*, and nothing here links against it.
* *Generated output*: none. `+generated/abi/+` is empty, and no header is
generated from these modules.

=== Check status (2026-10-14)

All four modules *typecheck* under Idris2 0.8.0
(`+bash panel-clades/scripts/check-abi.sh+`), with five expected
rejections in `+tests/reject/+`.

Before 2026-10-14, `+Types.idr+`, `+Layout.idr+` and `+Foreign.idr+` had
never typechecked:

* their module names did not match their paths;
* `+Types.idr+` had 11 errors;
* `+Layout.idr+` had more errors behind those;
* `+Foreign.idr+` used `+prim__getString+` before declaring it.

Several of their "proofs" were vacuous or false, and fixing them meant
redesigning, not patching:

* *Sizes by type.* `+cSizeOf : Platform -> Type -> Nat+` pattern-matched
on types, which Idris cannot do. It is now a closed universe:
`+CType+`, with `+cSizeOf+` / `+cAlignOf+` over its codes.
* *Size and alignment witnesses.* `+HasSize t n+` / `+HasAlignment t n+`
had a constructor for every `+n+`. Their one constructor now fixes `+n+` to
`+cSizeOf+` / `+cAlignOf+`, so a wrong size has no proof
(`+tests/reject/WasmPointerIsEightBytes.idr+`).
* *Equality on tags.* `+DecEq Result+` / `+DecEq CladeKind+` ended in
`+decEq _ _ = No absurd+`, which has no proof behind it. Both now decide
equality through a tag with a proved left inverse (`+decEqViaTag+`).
* *Alignment.* `+alignUpCorrect+` claimed divisibility by `+Refl+` for
arbitrary sizes. `+proveFieldsAligned+` did the same after a Boolean
`+mod+` test. `+alignUp+` is now units × alignment, so divisibility holds
by construction. Field alignment is decided by `+decDivides+`, whose
`+Just+` always carries a true equation.
* *Struct size.* `+calcStructSize+` ignored its fold accumulator. It is now
the furthest field end rounded up to the struct alignment, and
`+exampleSizeComputed+` checks it on the example (24 bytes).
* *Fake checks.* `+verifyAllPlatforms+` returned `+Right ()+` without
looking; it now runs `+checkCABI+` on every platform.
`+Verify.verifySizes+` / `+verifyAlignments+` printed "verified" and
checked nothing; they are replaced by checked facts (`+Verify.*+`).
* *Platform detection.* `+thisPlatform+` was a `+%runElab+` that returned
a constant and was described as detection. It is now that constant, and
says so.

=== Invariants

* `+%default total+` in every module.
* No `+believe_me+`, `+assert_total+`, `+assert_smaller+`, `+idris_crash+`
or `+unsafePerformIO+`. `+scripts/check-abi.sh+` greps for them and fails.

=== Adding New Proofs

[arabic]
. Put the module under `+PanelClades/ABI/+`, with a module name that
matches its path.
. List it in `+panel-clades-grades.ipkg+`. The gate fails on an unlisted
module.
. For each claim that a wrong value must not typecheck, add a
`+tests/reject/*.idr+` fixture: an `+invalid+` declaration and an
`+-- EXPECT:+` line with the error.
. Run `+bash panel-clades/scripts/check-abi.sh+`.
