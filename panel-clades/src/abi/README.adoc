== panel-clades/src/abi/ — Idris2 ABI Formal Proofs

=== Purpose

Formal verification of the panel-clades C ABI using Idris2 dependent
types. Proves memory layout correctness, alignment properties, and type
safety for the Zig FFI layer.

=== Boundary

* *Verified by*: Idris2 0.8.0 type checker — today only
`+PanelClades/ABI/Grades.idr+` (`+scripts/check-abi.sh+`); see Check status
* *Implemented by*: `+panel-clades/ffi/zig/+` (Zig FFI matching these
proofs)
* *Generated output*: `+generated/abi/*.h+` (C headers from ABI
definitions)

=== Files

=== Check status (2026-10-14)

* `+PanelClades/ABI/Grades.idr+` *typechecks* under Idris2 0.8.0 against
typed-wasm's grade kernel at the pin in `+scripts/fetch-siblings.sh+`
(`+bash panel-clades/scripts/check-abi.sh+`), with two expected rejections
(`+tests/reject/+`). Its lemmas are PROVEN; the `+neurosym-bridge+` budgets
are declared values (DESIGNED), not measurements.
* `+Types.idr+`, `+Layout.idr+`, `+Foreign.idr+` *do not typecheck* as of
`+787ac2e+`. Their module names (`+PanelClades.ABI.*+`) do not match their
paths, so Idris2 refuses them before checking anything. Laid out at
matching paths, `+Types.idr+` still has 11 errors: `+%runElab+` without
`+%language ElabReflection+`; `+DecEq+` used without
`+import Decidable.Equality+` (twice); `+So+` auto-proofs that cannot be
found for runtime values (`+createHandle+`, `+mkCladeId+`);
`+Bits (ptrSize p)+` where a type is expected (`+CPtr+`); pattern
matching on types (`+cSizeOf+`, `+cAlignOf+`); and `+allCladeKinds+` /
`+cladeKindExhaustive+`, where `+cladeKindCount+` is auto-bound as a
variable. The proof statuses below were therefore never machine-checked.
Fixing them is open (owner decision: some need redesign, e.g. sizes by
type).

=== Invariants

* `+%default total+` — all functions must be provably total
* 0 `+believe_me+` — no unsafe escape hatches
* 0 `+assert_total+` — no totality bypasses
* Proofs use `+So+` witnesses, `+Divides+` proofs, and `+DivideBy+`
constructors
* CladeKind exhaustiveness proven via vector-based witnesses (13
variants)

=== Adding New Proofs

[arabic]
. Define types in `+Types.idr+` with appropriate indices
. Write layout proofs in `+Layout.idr+` using `+FieldsAligned+` and
`+CABICompliant+`
. Declare FFI functions in `+Foreign.idr+`
. Verify with `+idris2 --check+` (requires `+.ipkg+` — currently
missing)
