Interactive browser for exploring panel clades, traits, inheritance chains, and permissions.

== Purpose

The Clade Browser provides a 4-tab interface for exploring the PanLL clade taxonomy:
Overview (stats grid, clade cards), By Kind (grouped by clade kinds), Traits (matrix
table), and Panel Map (panel-to-clade assignments with permission controls).

== Key Features

* 4-tab exploration interface (Overview, By Kind, Traits, Panel Map)
* OR-merge inheritance semantics with cycle detection
* 16 query functions for clade metadata
* Permission management (PermitAll/PermitOnly/PermitNone toggles)
* 4-tier metadata system (protocols, capabilities, dependencies, isolation)
* Dependency graph visualisation

== Integration Points

* Consumes **all clades** for taxonomy browsing
* Sibling of **panel-switcher** and **workspace**
* No backend required -- fully client-side
