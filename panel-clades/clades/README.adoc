== What are clades?

A **clade** is a taxonomic unit that defines what a PanLL panel _is_. Each
clade declares traits (capabilities), data shapes, interaction patterns, and
relationships to other clades. Panels inherit behaviour from their clade,
and users can customise how clades interact.

== Clade Kinds

[cols="1,3"]
|===
| Kind | Description

| **directive**
| Controls how other panels present and sequence work. Does not scan or build.

| **scanner**
| Analyses code, repos, or systems and produces findings.

| **builder**
| Constructs, compiles, or assembles artifacts.

| **database**
| Manages data stores and query interfaces.

| **network**
| Monitors or manages network infrastructure.

| **viewer**
| Displays information without modifying state.

| **ai**
| Multi-provider neural interface for agentic reasoning.

| **loader**
| Scans and configures panels from repository structure.

| **meta**
| Governance, compliance, and licensing hub.

| **bridge**
| Federates with external tools (editors, terminals) via protocol bridges.

| **terminal**
| Embedded shell / REPL with session recording and collaborative features.
|===

== Adding a new clade

. Create a directory under `clades/` named after the clade (lowercase, hyphenated)
. Add `<CLADE-NAME>.a2ml` — machine-readable clade definition with traits
. Add `README.adoc` — directory overview
. Optionally add `<CLADE-NAME>.adoc` — human-readable reference documentation
. Update this registry table
. Create corresponding panel files in PanLL `src/` (model, cmd, module, component)
. Wire into PanLL (PanelSwitcherModel, Msg, Model, Update, View, PanelRegistry)
