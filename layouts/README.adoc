== What Are These?

Layout presets configure which panes, sub-panels, and tools are visible,
sized, and prioritised for a given discipline. They are the "recipes"
behind PanLL's global viewshift dropdown.

Each preset is a https://github.com/hyperpolymath/k9-svc[K9 Self-Validating Component]
at *Yard* security level — pure Nickel configuration with contracts, no I/O.

== Contract Enforcement

The `pedigree-layout.ncl` schema enforces:

* Pane sizes *must* sum to exactly 100
* Panel visibility is one of `Expanded`, `Collapsed`, or `Hidden`
* Default provers are from the known ECHIDNA catalog
* All fields are typed (Nickel rejects malformed presets at evaluation time)

== Validating a Preset

[source,bash]
----
nickel typecheck layouts/logic-and-proofs.k9.ncl
nickel export layouts/logic-and-proofs.k9.ncl --format json
----

== Creating a Custom Layout

. Copy an existing preset
. Modify pane sizes (must sum to 100)
. Change panel visibility and prover priority
. Run `nickel typecheck` to validate

Community-contributed presets are welcome — submit a PR with your `.k9.ncl`
file and it will be validated against the pedigree schema automatically.
