== Directory Structure

[cols="1,3"]
|===
| Directory | Contents

| `architecture/`
| System architecture — topology map, ASCII diagrams, panel inventory,
  Tauri command reference

| `decisions/`
| Design decisions (DD-001 to DD-018) and the eNSAID+IDApTIK combined
  specification

| `design/`
| Session design documents — dated snapshots of design thinking from
  specific sessions

| `guides/`
| User and developer guides — quick starts, TEA guide, testing, LLM
  warmup context

| `status/`
| Status reports and audits — completion snapshots, taxonomy audits,
  feature build status

| `archive/`
| Historical documents — completed migration guides (ReScript-TEA,
  npm-to-Deno) kept for reference

| `research/`
| Academic work — the Binary Star paper (arXiv draft), matrix discussion
|===
