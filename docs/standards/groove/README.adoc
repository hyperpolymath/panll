== Usage Guidelines

=== When to Use Soft Groove

* Optional components (Provisioner, Configurator)
* Plugin cartridges
* Experimental features
* Non-critical services
* Components that may be disabled

=== When to Use Hard Groove

* Core system components (Panel System, TEA Runtime)
* Performance-critical services
* Components that must always be available
* Tightly coupled subsystems
* Foundational infrastructure

=== Decision Flow

. Is the component optional?
  [yes] → Use Soft Groove
  [no] → Continue

. Is it performance-critical?
  [yes] → Use Hard Groove
  [no] → Continue

. Is it core infrastructure?
  [yes] → Use Hard Groove
  [no] → Use Soft Groove
