==== Added (2026-10-26 — every panel-backend command registered)

* *The IPC table in `+src-gossamer/src/ipc.rs+` now registers all 239
panel-backend commands* (the coprocessor pilot was 10). With the 36 in
`+main.rs+`, the desktop shell exposes 275. Command and argument names
match the pre-#107 frontend's `+invoke()+` calls.
* *Event pump.* `+main.rs+` delivers the events backend modules queue
through `+compat+` (AI streaming chunks, file-watcher events) to the
webview every 50 ms.
* A test fails if a public handler in a command module is not
registered (`+every_backend_command_is_registered+`).

==== Changed (2026-10-14 — orphaned Rust backend modules wired into the lib)

* *43 orphaned modules under `+src-gossamer/src/+` now compile.* They were
declared by no crate root, so they were never compiled, linted or tested.
All are GTK/WebKit-free and are now `+pub mod+` in `+lib.rs+`;
`+main.rs+` still adds only `+system_tray+`. `+cargo test --lib+` runs
285 tests (was 23).
* Clippy (`+-D warnings+`) and rustfmt fixes in the newly compiled code.
Most were blank lines left where `+#[tauri::command]+` attributes had
been deleted. `+minter_mint_panel+` now takes a `+MintRequest+` instead
of 12 positional arguments.
* Tauri leftovers removed from `+compat+`, `+error+`
(`+to_tauri_result+` → `+to_command_result+`), `+cloudguard::commands+`
and `+ums_cartridge::commands+`.
* The handlers in these modules are *not yet registered* in
`+register_commands+` (`+main.rs+`); that is follow-up work. The
`+Cargo.toml+` header ("All 103 command handlers are registered") and
`+EXPLAINME-new.adoc+` ("270 migrated commands") now state the real
figure: 36 registered.

==== Fixed (2026-10-14 — panel-clades Types/Layout/Foreign typecheck)

* `+Types.idr+`, `+Layout.idr+` and `+Foreign.idr+` had never typechecked.
They now live at their module paths under
`+panel-clades/src/abi/PanelClades/ABI/+`, typecheck under Idris2 0.8.0,
and are built by `+check-abi.sh+` and CI with `+Grades.idr+`.
* Changes that alter meaning:
** C sizes are a closed universe (`+CType+`), not a match on `+Type+`.
** `+HasSize+` / `+HasAlignment+` admit only the true size.
** `+DecEq+` goes through a retracted tag, not `+No absurd+`.
** `+alignUp+` is units × alignment, so `+alignUpCorrect+` holds by
construction.
** Field alignment is decided by an equation (`+decDivides+`).
** `+calcStructSize+` is the furthest field end, rounded up.
** `+verifyAllPlatforms+` now checks every platform.
** The `+verifySizes+` / `+verifyAlignments+` stubs, which only printed
"verified", are replaced by checked facts.
* Three more expected rejections: `+WasmPointerIsEightBytes+`,
`+NullHandle+`, `+MisalignedField+`.
* `+check-abi.sh+` now fails on a `+PanelClades/ABI+` module missing from the
ipkg, and on `+believe_me+` / `+assert_total+` / `+assert_smaller+` /
`+idris_crash+` / `+unsafePerformIO+`.
* *Still open:* nothing checks that the Zig FFI agrees with these
definitions (`+panel-clades/src/abi/README.adoc+`, Proof status).

==== Changed (2026-10-14 — clade budgets come from the clade config)

* A clade's declared resource budgets live in the `+resources+` block of its
`+clades/<clade>/config.k9.ncl+`, not in Idris.
* `+panel-clades/scripts/gen-budgets.sh+` generates
`+PanelClades/ABI/Budgets.idr+` from those blocks. `+check-abi.sh+` fails
when the file is stale or a block is malformed.
* `+CladeResourceContract+` is parametric in a `+CladeBudget+`.
`+declaredContract+` builds a contract from a config's values, and
typechecks only when the declared peak fits the declared budget and the
declared loss fits the tolerance (`+tests/reject/BudgetTooSmall.idr+`).
* `+neurosym-bridge+` declares peak 48, drift 16, budget 64, loss 2,
tolerance 3. These are DESIGNED values, not measurements.
* The occupancy-vs-cost witnesses (64 vs 96) now use illustrative phases
(`+examplePhase+`), independent of any config.

==== Added (2026-10-14 — graded clade contracts over typed-wasm's grade kernel, PWL-01)

* `+panel-clades/src/abi/PanelClades/ABI/Grades.idr+` grades a clade's
resource contract in typed-wasm's grade kernel, pinned by
`+panel-clades/scripts/fetch-siblings.sh+` at typed-wasm `+117bbf8+`. Panel
state is graded by occupancy (HWM) and the Panel-N → Panel-W crossing by
loss (Loss). It includes the `+neurosym-bridge+` contract (DESIGNED: the
budgets are declared values) and the computed occupancy-vs-cost witness
(64 vs 96).
* `+panel-clades/scripts/check-abi.sh+` builds it against the kernel and runs
two expected rejections (`+panel-clades/tests/reject/+`). It runs in CI
(`+build-validation.yml+`, job `+panel-clades-abi+`).
* `+schema/typell-grade.schema.json+` defines the `+{grade, algebra}+` wire
payload for TypeLL (DESIGNED).
* *Finding:* `+panel-clades/src/abi/{Types,Layout,Foreign}.idr+` do not
typecheck, because of module/path mismatch and 11 errors in `+Types.idr+`. The
ABI README now says so.

==== Fixed (2026-03-23 — TEA Crash Recovery)

* *RuntimeBridge.invoke browser-mode crash* —
`+JsError.throwWithMessage+` threw synchronously instead of returning a
rejected Promise, killing the TEA dispatch loop on the first backend
call in browser mode. Fixed to use `+Promise.reject(new Error(...))+`.
Same fix applied to `+Dialog.openDialog+` and Fs methods.
* *TEA dispatch loop freeze* — Added try/catch around
`+processMessage+`, `+render+`, and `+subscriptions+` in `+Tea_App.res+`
so one thrown exception no longer permanently freezes all event
handling.
* *ReScript build errors* — `+open+` reserved keyword in
`+RuntimeBridge.Dialog+` renamed to `+openDialog+` (propagated to
`+GossamerCmd.res+`, `+RepoLoaderCmd.res+`); `+String.indexOf+` return
type mismatch in `+RuntimeResolver.res+`; duplicate `+detectRuntime+`
symbol renamed to `+currentRuntime+`.
* *Missing panel view cases* — Added 13 placeholder view cases in
`+View.res+` for GSA, Burble, and IDApTIK panels registered in the Clade
system.
